A second set of N2 patterns, focused on describing appearances, giving
advice, and expressing emphasis.

| Pattern | Connects to | Meaning |
|---|---|---|
| ～げ | adj-stem / V-stem | looks ~; seeming ~ (appearance) |
| ～っぽい | N / V-stem / adj-stem | -ish; tends to; has a ~ quality |
| ～ことだ | V-dict / V-ない | you should; the best thing is to |
| ～ものだ | V-dict / V-た / adj | one naturally does; used to |
| ～さえ…ば | N さえ / V-stem さえ | if only ~ then |
| ～どころではない | V-dict / N | this is no time for; far from it |
| ～かのようだ | plain clause | as if; as though |
| ～にすぎない | plain clause / N | no more than; merely |
| ～にきまっている | plain clause | is bound to; surely |
| ～かねる | V-stem | cannot quite; unable to |

**Examples**

- 子どもが寂し**げ**な顔をしている。 — The child has a *lonely-looking* face.
- 彼は忘れ**っぽい**ので、メモを取る。 — He *tends to be forgetful*, so he takes notes.
- 健康になりたいなら、運動する**ことだ**。 — If you want to be healthy, you *should* exercise.
- 子どもの頃はよく泣いた**ものだ**。 — As a child, I *used to* cry a lot.
- お金**さえ**あれ**ば**、何でも買える。 — *If only* you have money, you can buy anything.
- 忙しくて、旅行**どころではない**。 — I'm so busy this is *no time for* travel.

～げ and ～っぽい both describe an impression, but ～っぽい can also mean a
strong tendency (怒りっぽい = quick to anger).
