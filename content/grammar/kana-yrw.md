The last rows of the hiragana chart.

**Y row** (only three)

| Kana | Rōmaji |
|---|---|
| や | ya |
| ゆ | yu |
| よ | yo |

**R row** (a soft, tapped *r*, between *r* and *l*)

| Kana | Rōmaji |
|---|---|
| ら | ra |
| り | ri |
| る | ru |
| れ | re |
| ろ | ro |

**W row and ん**

| Kana | Rōmaji |
|---|---|
| わ | wa |
| を | wo (o) |
| ん | n |

を is read **o** and is used only as the object particle. **ん** is the only kana
that is a single consonant — it never starts a word.
