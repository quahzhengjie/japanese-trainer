A first set of common N2 sentence patterns. Each attaches to a particular
verb or clause form, so pay attention to what comes *before* the pattern.

| Pattern | Connects to | Meaning |
|---|---|---|
| ～うちに | V-dict / V-ない / adj / N の | while; before (a state changes) |
| ～ばかり | V-た / N | nothing but; just (did something) |
| ～たばかり | V-た | just finished doing |
| ～わけだ | plain clause | that's why; it follows that |
| ～に違いない | plain clause | must be; no doubt that |
| ～にもかかわらず | plain clause / N | in spite of |
| ～ついでに | V-dict / V-た / N の | while at it; on the same occasion |
| ～うえに | plain clause | on top of; in addition |
| ～どころか | plain clause / N | far from; on the contrary |
| ～たびに | V-dict / N の | every time; whenever |

**Examples**

- 明るい**うちに**家へ帰りましょう。 — Let's go home *while* it's still light.
- さっき昼ご飯を食べた**ばかり**だ。 — I *just* ate lunch.
- 電車が遅れた。だから遅刻した**わけだ**。 — The train was late — *that's why* I was late.
- 彼は来ない**に違いない**。 — He *must* not be coming.
- 雨**にもかかわらず**、試合は行われた。 — *In spite of* the rain, the match was held.
- 買い物の**ついでに**郵便局に寄った。 — *While* shopping, I stopped by the post office.

Note that ～うちに with a negative verb (V-ない うちに) means "before ~ happens".
