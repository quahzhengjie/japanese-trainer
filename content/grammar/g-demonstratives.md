title: これ・それ・あれ — the ko-so-a words

Japanese demonstratives form a neat **ko / so / a / do** grid based on distance.

| Near me | Near you | Away from both | Question |
|---|---|---|---|
| これ this (thing) | それ that | あれ that (over there) | どれ which |
| この this … | その that … | あの that … | どの which … |
| ここ here | そこ there | あそこ over there | どこ where |

**これ / それ / あれ** stand alone as nouns:
> これ**は** ペンです。 — This is a pen.

**この / その / あの** must be followed by a noun:
> **この** ほんを よみます。 — I read this book.

Use **ここ / そこ / あそこ** for places:
> トイレは **あそこ**です。 — The toilet is over there.
